# @sunstone-partners/ensemble-react

React 18+ conventions skill for Claude Code.

## Installation

```bash
claude plugin install @sunstone-partners/ensemble-react
```

## Contents

- `skills/react/SKILL.md` - react-framework conventions

Skills are short conventions-and-gotchas notes (the model already knows the framework basics); they are loaded automatically by Claude Code from `skills/`.
