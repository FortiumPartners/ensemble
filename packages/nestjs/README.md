# @sunstone-partners/ensemble-nestjs

NestJS conventions skill for Claude Code.

## Installation

```bash
claude plugin install @sunstone-partners/ensemble-nestjs
```

## Contents

- `skills/nestjs/SKILL.md` - nestjs-framework conventions

Skills are short conventions-and-gotchas notes (the model already knows the framework basics); they are loaded automatically by Claude Code from `skills/`.
